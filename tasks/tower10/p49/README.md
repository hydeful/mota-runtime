# P49 手绘一层小魔塔：原样地图与独立认证

按用户确认的9×5地图构造，保留初始HP400、攻击10、防御10、零钥匙。
铁剑攻击+10，铁盾防御+10。击败M，原引擎完成该步结算后立即通关，剩余HP计分。

这版地图可解，而且**所有合法完整交互路线都能通关**。它不满足随机通关率万分之一至千分之一的期望，但有明显的剩血优化空间：全局最低成功剩血2，最高574。
这只是地图认证，不是学习效果证据。未启动训练、MCTS能力评价或AutoDL实验。

## 地图

```text
p # p # X # q # q
A # B # M # C # D
Y . . K . K . . Y
# # # K . K # # #
S B Y . @ . Y B T
```

- `#` 墙，`.` 空地，`@` 起点，`X` 无对象的普通空地，无任务作用。
- `K` 黄钥匙，`Y` 黄门；各4个。下方两只怪物也是B，使用相同属性。
- `p` 原红血瓶，恢复50；`q` 原蓝血瓶，恢复200。没有HP上限截断。
- `S` 铁剑，`T` 铁盾；对象、物品效果、钥匙扣除均来自原规则。
- 坐标从左上角 `(x=0,y=0)` 起，向右/向下增加；楼层ID为MT1。

怪物数据逐字段复制自固定P48静态规则，未调整数值：

|标记|原ID|名称|HP|攻击|防御|
|---|---|---|---:|---:|---:|
|A|greenSlime|绿史莱姆|35|18|1|
|B|redSlime|红史莱姆|45|20|2|
|C|bat|小蝙蝠|35|38|3|
|D|bluePriest|初级法师|60|32|8|
|M|skeletonSoldier|骷髅士兵|55|52|12|

C曾被语音描述为“小公主”，原引擎无此名称；用户随后明确确认采用小蝙蝠。
原数值的每一项不必严格按A→D递增，例如D攻击低于C，但生命和防御更高。
M初始不可破防，因此铁剑是通关必需品。

## 认证结果

`acceptance/exhaustive.json`：枚举76849个约简状态，覆盖1,672,391,733,729条完整合法交互序列。
每条序列都成功，均匀合法交互策略的成功概率为1。成功终局剩血范围2–574。
约简键为已完成对象集合、HP及英雄位置。攻击、防御、钥匙和金币由已完成集合决定；
此图没有事件条件、楼梯或飞行，因此方向、步数和展示旗标不影响后续决策。
约简仅用于独立验收，训练环境没有使用该枚举结果。

`acceptance/sample.json`：固定种子49101、49102、49103，每组10000局，均为10000/10000通关。
合计30000/30000，Wilson 95%区间约[99.9872%,100%]；三组成功平均剩血约185.72、187.46、185.57。
抽样不替代穷举证明；单看抽样不能推断严格100%。

随机定义：每步在**当前合法有效对象交互**中等概率选择，从固定初态重新开始，直到击败M或无有效交互。
这张图每个对象只有一个动作，因此按动作与按交互点等概率一致。
不是随机方向走路，不会随机选择已知必死战斗，也不是随机初始化网络加MCTS。
没有预算截断：每步必须完成一个新对象，每局最多21次交互。

最高/最低剩血路线均逐步使用独立未加速参考引擎复演，完整transition结果、输入未变性、终局和终局后拒绝行为均核对一致。
随机采样中每个种子的前20局及首条成功轨迹也做完整参考复演，不声称逐步复演了全部30000局。

一个最短通关例子（仅独立验收用）：
`(3,3)钥匙 → (2,4)黄门 → (1,4)B → (0,4)铁剑 → (4,1)M`，最终98HP。
最高分路线先拿盾，让后续史莱姆零战损，再取剑并领取有收益的血瓶，最终574HP。
所有认证路线、最优值及报告放在`acceptance/`，不作为训练标签、先验或路线库。

## 试玩前端

`web/src/`是无前端框架的静态页面，支持地图、动态可交互高亮、怪物属性与战损预览、
手动交互、撤销、重开、随机一步/整局、交互日志导出及拓扑视图。
使用本地打包的Pyodide 0.27.7执行**字节相同的Python参考引擎**，没有JavaScript战斗器。
页面加载时校验引擎和初态SHA；Python桥接与CPython适配器的完整状态一致性另有测试。
首次加载约14MB运行环境；字体加载失败时使用系统字体。
怪物像素图为本次绘制的SVG示意，没有复制游戏图片素材。

在仓库根目录运行：

```bash
python -m tasks.tower10.p49.build_web
python -m http.server 8765 --directory tasks/tower10/p49/web/dist
```

打开`http://localhost:8765`。构建命令首次下载固定版本Pyodide并校验归档SHA256，后续复用已校验文件。
不能双击HTML后依赖file协议加载Python资源，应使用HTTP服务。

`acceptance/browser_qa.json`记录实际Chromium验证：桌面1440×1100、手机390×844，45格/14墙/初始4个合法交互，
手动5步98HP通关，随机试玩通关，撤销/重开/拓扑切换正常，无页面脚本错误或手机横向溢出。

原P45环境仍绑定550×13×13、713动作、十层初态、奖励界和恢复合同；没有修改它或旧环境。

后续学习适配需单独登记：地图与checkpoint身份、观测尺寸/平面、动作词表与mask、
GOAL/失败及奖励尺度、训练触发门槛、样本schema和恢复兼容性。
保留原策略/价值网络结构、MCTS与学习流程连续性，不能让认证答案进入这些路径。

本图通关率已是100%，未来评价若只看通关率会出现天花板。
可以在相同搜索预算下比较N0与训练后网络的剩血分布，并验证新模型确实参与后续搜索；
