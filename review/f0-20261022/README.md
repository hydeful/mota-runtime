## F0实际做了什么

运行冻结R48十层参考任务、原地图CNN，而非T49对象拓扑网络。本次不比较学习架构，也不重开P49研究。新随机N0，seed=4201；前缀seed=6201。原确定性CPU后端，intra/inter-op均为1线程，Torch 2.14.1+cpu、NumPy 2.3.5。

两次尝试各从同一初态生成4个真实决策，每决策100新增MCTS模拟并保留子树复用。两次状态序列相同，合计仍只有5个唯一浅层状态。原搜索最大内部深度为3。没有完整终局、z、训练组批、SGD、正式回流或完整C0。

每次16组固定B=1输入，各重复3次、交替测量臂顺序：旧路径恢复动态状态、encode、计算mask、stack；新离线路径从事先构建的只读数组中复制取行。每次48组X/mask与同后端logits/value精确一致，两次共96组。不是96个独立状态。最终版本还检查完整模型状态未变化。

资源：可见cgroup v2 CPU配额4核，affinity为5个CPU；内存限制16GiB。隐藏祖先约束未知；内存limit-current不是保留可用内存。
