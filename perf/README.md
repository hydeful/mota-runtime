# P48 AutoDL 自动性能探测

这是实验入口，不改变原 `p45` CPU入口或默认算法。唯一稳定分母为公开
`f0825385c6bb5914b653679d14635a2b1393cf87`，对应源提交
`63bdd80216edf825d887bc5316eb0ad78e7250ad`。22个原始运行文件逐字节保留。

## 做什么

自动执行原版600秒；相同N0/种子/四局工作量筛选；候选真实训练、发布、恢复与
更新模型消费门禁；候选600秒；尽量按BA顺序完成候选/原版各300秒重复。
从提交的合格位置产能比较完整闭环，训练应做/已做/未完成的SGD分别报告。
找不到收益就保留负结果，不改默认，不承诺10倍或学习增强。

候选覆盖：

- CPU：2/4路采集共享唯一同步SGD，持久worker raw P/V缓存；按完成顺序接收结果，
  最终仍按episode id提交四局cohort。CPU推理/训练1/2/4线程先做局部筛选。
- GPU：独立进程批量推理、跨actor raw P/V共享/批内去重；训练可使用CPU或CUDA。
  GPU训练是CUDA网络前后向/SGD＋CPU目标/损失/编码，不伪称所有步骤都在GPU。
  批量等待0.2ms/1ms；四局同步屏障下实际同时请求最多4，16/64批仅做局部容量测试。
- 保存：P46实验性C-pickle状态打包＋一次性JSON输出；保存频率、原子rename、
  文件和目录fsync保持不变，原torch.load可读，不减少训练或持久化边界。
- 表示：完整float32观测SHA256直接读连续内存，非连续数组回退原字节顺序；
  哈希值和缓存键不变。规则实现不改。
- 通信/调度：队列、发包/响应等待、模型分发、实际GPU批量、父进程reconcile、
  各actor墙钟/CPU与资源采样。父等待包含actor计算，不能全算成通信浪费。

为什么不机械跑8/16个actor：当前保留P45四局cohort＋同步训练屏障，同时最多4局。
增加到8/16只会空闲，故标记“当前调度不适用/未测”，不推断别的多cohort调度也无收益。
对象平面缓存不重试：已有三次完整流程变慢的证据，没有新机制解释它会改善。
局部倍率不相乘；短筛选的预测分数只用于选候选，最终600秒闭环决定实测结果。

## 安装（不启动实验，不动旧环境）

交付消息提供本版本完整40位提交。以该值替换COMMIT，单行执行：

```bash
curl -fsSL https://raw.githubusercontent.com/hydeful/mota-runtime/COMMIT/perf/install.sh -o /root/autodl-tmp/p48-perf-install.sh && bash /root/autodl-tmp/p48-perf-install.sh COMMIT auto
```

安装写入 `/root/autodl-tmp/p48-perf`，按提交隔离源码/CPU环境/GPU环境。
CPU精确使用Torch2.14.1+cpu、NumPy2.3.5；可复用满足要求的预装依赖。
GPU环境完全独立：驱动580+优先官方2.14.1/cu130，失败或旧驱动尝试2.11.0/cu128。
CUDA12.8源没有2.14.1 wheel，不会误把CPU安装当GPU。
跨Torch版本也是工程方案的一部分，会明确记录，不能把倍率全归因于GPU硬件。
失败时保留gpu-install.log并把GPU标记不可用；`required`代替`auto`可要求GPU安装成功。
`off`只准备CPU。GPU分支当前需要AutoDL真实验证，本地没有GPU不声称通过。

安装和小自检耗时单列。微实验、CUDA编译/预热、失败、启动、停止和导出均在
启动实验后的全局预算内。程序不在实验计时过程中安装包。

## 固定操作（每条单行）

```bash
/root/autodl-tmp/p48-perf/bin/mota-perf start probe1 --budget 3600
```

这会创建独立实验目录，后台运行，不读写旧 `cloud600`。可关闭终端。
只启动这一份实验；不要用新名称重开以替代失败或延长本轮预算。

|操作|命令|
|---|---|
|简短进度|`/root/autodl-tmp/p48-perf/bin/mota-perf status probe1`|
|安全停止|`/root/autodl-tmp/p48-perf/bin/mota-perf stop probe1`|
|恢复控制程序|`/root/autodl-tmp/p48-perf/bin/mota-perf resume probe1`|
|导出当前结果|`/root/autodl-tmp/p48-perf/bin/mota-perf export probe1`|
|安装自检|`/root/autodl-tmp/p48-perf/bin/mota-perf check`|

预算从start启动控制程序时开始，包含准备和子进程。绝对UTC截止时间持久保存；
重启、暂停、迁移同目录不重置。到期后拒绝恢复。已有实验名拒绝覆盖。
控制程序与实验子进程共同持flock，避免控制程序退出后又启动第二个写入者。
独立子进程看门狗和进程组停止是额外保护。

暂停的600秒片段永远不拼成一个完整600秒结果。resume先收回已完整完成的结果；
不足窗口的尝试保留为未完成，时间足够才开始单独的新尝试，仍受原总截止时间约束。
候选自身断点的模型/优化器/RNG/数据恢复在学习门禁中真实核验。
如安装新版本后需恢复旧实验，应使用其原源码提交对应的CPU环境，代码不混用。

程序为完整对照/重复保留预算，临近截止不再开新项；提前停止计算，为保存和导出留余量。
按实际筛选时间可早于3600秒结束；未执行或未完成项如实标记，绝不凑满或补造数据。

## 结果

自动生成：`/root/autodl-tmp/p48-perf/experiments/probe1/results.zip`。
用JupyterLab文件列表下载此文件返回。正常结束自动导出；手动export也可取当前快照。
运行中快照不是最终一致性报告，JSONL末尾可能仍在追加。

包内有SUMMARY.txt、summary.csv、summary.json、逐项配置/结果/错误、CPU/内存/GPU资源
JSONL、必要控制/原始事件日志、终局数据和模型版本/训练消费核验。
不含checkpoint、权重、CPU数值门禁NPZ或认证环境变量。完整运行工件仍留在数据盘，
不自动上传GitHub。GPU安装日志只复制经URL/token脱敏的末尾片段。

每小时位置/局数均明确标为短时外推，不是一小时实测。主比较用完整采集调用的墙钟，
其中含搜索/校验/训练/发布/保存及pool启动；外层另报解释器/初始化/事后独立规则审计。
独占计时只在同一进程内可相加，进程间、原版search计时和新增计时不能重复相加。
sumRSS重复计共享页且采样峰值是下界；GPU利用率是整卡采样，可能含其它作业。
CPU利用率按cgroup配额核数算，绝不以208可见CPU当作208配额。

## 正确性和结论门槛

所有正式窗口都从本实验中新随机生成的CPU2.14.1 N0开始，同一seed对应同一N0权重hash；
跨设备共享的只是本次随机N0，不是历史权重或训练数据。原版/候选600秒seed4801，
BA重复300秒seed4802，候选学习恢复门禁seed4803。微实验只读本次新基线数据，不回灌正式链。

候选进入600秒前必须：通过当前状态/标签/100次搜索/账本检查，真实达到自然训练门槛，
完成更新，恢复前后完整逻辑指纹一致，再以新模型继续搜索。
raw P/V键始终包含实际权重hash、schema和完整观测hash，不缓存根噪声或最终策略。
更新后worker/service缓存清空或隔离，完整模型验证hash后才原子切换。

CUDA预设门槛：FP32，禁TF32和非确定性kernel；推理abs1e-5/rel1e-4；
真实batch64单步的损失、梯度范数、参数/BN状态abs1e-5/rel1e-3，整数状态精确。
GPU和其它CPU线程实现都对照CPU2.14.1生成的本次固定数值见证；不看结果后放宽。
不要求GPU完整轨迹逐位相同，但规则、样本、预算、版本和训练消费必须一致有效。

只有600秒和300秒重复均支持主要产能至少约20%提高、无额外训练欠账，才提示可评审默认。
脚本不会自动切换P45默认。脚本交付、实测性能、是否设默认是三项独立结论。
